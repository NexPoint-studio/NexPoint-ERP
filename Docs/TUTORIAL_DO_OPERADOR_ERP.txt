======================================================================
01. PARA QUE SERVE CADA PARTE DO SISTEMA
======================================================================

CLIENTES
Guarda os dados das pessoas e empresas atendidas: nome, contato, endereço,
observações, visitas e atendimentos gerados pelas Notas. Mostra o último retorno,
o último serviço e há quanto tempo não há um novo atendimento.

SERVIÇOS
Na área operacional, permite consultar o catálogo, criar uma Nota de Serviço e
acompanhar as Notas. A gestão de catálogo, categorias, unidades e preços fica na
Administração.

CAIXA
Registra dinheiro efetivamente realizado. O operador confere apenas os próprios
lançamentos recentes; saldo, totais e relatórios globais ficam no Financeiro para
quem possui a permissão adequada.

ADMINISTRAÇÃO
É a área funcional do Proprietário: visão geral, gestão de Serviços, Financeiro,
formas de pagamento e taxas, usuários e permissões e dados da empresa.

COMO ESSAS PARTES TRABALHAM JUNTAS

O fluxo principal é Cliente → Nota de Serviço → Pagamento → Caixa:

- Cadastrar um cliente não cria visita, Nota nem entrada no Caixa.
- Registrar uma visita não cria cobrança nem recebimento.
- Criar uma Nota registra um atendimento no histórico do Cliente e congela os
  serviços, unidades e preços daquele momento.
- Confirmar o pagamento integral de uma Nota positiva cria uma entrada automática
  no Caixa. Não faça outra entrada manual para o mesmo recebimento.
- Nota de total zero fica paga sem Pagamento e sem Caixa.
- Entrada e Saída manuais continuam disponíveis para valores que não vieram do
  recebimento de uma Nota.
- Alterações posteriores de catálogo ou taxa não reescrevem os históricos.

O sistema funciona neste computador, inclusive sem internet. Os registros
ficam guardados aqui. Este ERP não compartilha os dados automaticamente
com celular, outro computador ou o sistema oficial NIL LAV.


======================================================================
02. ENTRAR, NAVEGAR E SAIR
======================================================================

ENTRAR

1. Abra o aplicativo ERP disponibilizado neste computador.
2. Na janela de login, confira o campo "Usuário".
3. Para o ambiente de teste atual, use:

   Usuário: adm
   Senha:   adm

4. Clique em "Entrar".
5. A tela inicial após o login é a Lista de Clientes.

Os campos podem já vir preenchidos para facilitar o teste. Se a sua sessão
continuar aberta, o aplicativo pode entrar diretamente, sem pedir login.
Não há uma opção "Manter conectado" para marcar nesta tela atual.

Essas credenciais pertencem ao ERP local de teste; este guia não muda
as contas dos outros sistemas.

ENTENDER A NAVEGAÇÃO

- Menu lateral: escolhe o módulo, como Clientes, Serviços ou Caixa.
- Abas no alto: escolhem a função dentro do módulo atual.
- "Ver": abre os detalhes do registro da linha escolhida.
- "Editar": abre o formulário para corrigir os dados permitidos.
- "Anterior" e "Próxima": passam entre páginas de uma lista.
- Em janelas menores, use o botão "Abrir menu" se o menu estiver recolhido.
- Tabelas largas podem precisar ser deslizadas para o lado para mostrar
  todas as colunas e ações.

SALVAR UM FORMULÁRIO

1. Preencha os campos. O asterisco (*) indica um campo obrigatório.
2. Confira as informações antes de clicar no botão de salvar.
3. Clique uma vez e aguarde a resposta.
4. Se aparecer erro, leia a mensagem, corrija o campo e tente novamente.
5. Confira o resultado na ficha ou na lista correspondente.

Digitar não salva automaticamente. Trocar de tela ou fechar a janela antes
de salvar pode perder o que estava sendo preenchido.

"Cancelar" dentro de um formulário normalmente significa desistir daquela
edição. "Cancelar lançamento", no Caixa, tem outro efeito: retira um
lançamento já salvo dos cálculos. Veja a seção 12 antes de usar.

SAIR

1. Ao terminar, use o botão "Sair" no rodapé do menu lateral, perto do
   nome do usuário. Ele aparece como um ícone de saída.
2. Confira se voltou à tela de login.
3. Feche a janela, se não for mais usar o aplicativo.

Fechar pelo X não é o mesmo que usar "Sair": a sessão pode ser mantida.
Os dados que já foram salvos permanecem guardados.


======================================================================
03. CLIENTES: CADASTRAR E CONSULTAR
======================================================================

CADASTRAR UMA PESSOA

1. Entre em "Clientes".
2. Clique em "Novo cliente" ou "+ Novo cliente".
3. Escolha "Pessoa".
4. Preencha "Nome completo", que é obrigatório.
5. Se tiver as informações, preencha CPF e data de nascimento.
6. Preencha telefone, WhatsApp e e-mail, quando disponíveis.
7. Preencha o endereço manualmente: CEP, rua, número, complemento,
   bairro, cidade e estado. Use duas letras para o estado, como SP.
8. Em "Observações", escreva informações úteis para o atendimento.
9. Para um cadastro normal, deixe "Cliente ativo no cadastro" marcado.
10. Clique em "Salvar cliente" e confira a ficha apresentada.

CADASTRAR UMA EMPRESA

1. Abra "Novo cliente" e escolha "Empresa".
2. Preencha "Razão social", que é obrigatória.
3. Se houver, informe nome fantasia, CNPJ e responsável/contato principal.
4. Complete contato, endereço e observações como no cadastro de pessoa.
5. Clique em "Salvar cliente".

DOCUMENTOS E POSSÍVEIS DUPLICIDADES

- CPF e CNPJ são opcionais. Se forem preenchidos, precisam ser válidos.
- Essa conferência não confirma titularidade ou situação na Receita Federal.
- Um documento já cadastrado não pode ser repetido em outro cliente.
- Telefone ou WhatsApp repetido pode gerar um aviso de possível duplicidade.
- Use "Ver cliente existente" para conferir se é a mesma pessoa.
- "Cadastrar mesmo assim" só deve ser usado após conferir que é outro
  cliente, por exemplo quando duas pessoas usam o mesmo telefone.
- O endereço não é preenchido automaticamente pelo CEP.
- Os campos de contato guardam informações; não enviam WhatsApp ou e-mail.
- O aviso de duplicidade não encontra necessariamente todo cadastro repetido.
  Confira também a lista antes de cadastrar novamente.

CONSULTAR A LISTA

1. Clique em "Clientes" e depois em "Lista".
2. Veja os clientes apresentados e use "Anterior" ou "Próxima" quando
   houver mais de uma página.
3. Clique em "Ver" na linha do cliente para abrir sua ficha.

Os cartões no alto mostram total de clientes, clientes ativos, novos no
mês e clientes classificados como "Há muito tempo". São indicadores gerais
do cadastro; não representam necessariamente apenas as linhas filtradas.

O QUE FAZ CADA FILTRO DA LISTA

- "Buscar cliente": procura por nome, contato, documento ou e-mail.
- "Tipo": separa Pessoa e Empresa.
- "Cadastro": separa Ativos e Inativos.
- "Relacionamento": separa Nunca atendidos, Recentes e faixas de dias.
- "Sem atividade há mais de": procura quem já teve atividade registrada
  e está há determinado número de dias sem uma nova atividade.
- "Ordenar por": muda a ordem, por nome, cadastro ou última visita.
- "Por página": escolhe 25, 50 ou 100 clientes por página.
- "Pesquisar e filtrar": aplica as escolhas.
- "Limpar": volta à lista inicial.

======================================================================
04. CLIENTES: VISITAS, RELACIONAMENTO E HISTÓRICO
======================================================================

O QUE APARECE NA FICHA

Ao clicar em "Ver", você encontra contato, endereço, situação do cadastro,
informações de relacionamento, observações e "Atividades do cliente".
Algumas informações, como nascimento, responsável da empresa e complemento
do endereço, precisam ser consultadas em "Editar", pois não aparecem completas
nessa visualização da ficha. Se apenas consultou, saia sem salvar alterações.

REGISTRAR UMA VISITA

1. Abra a ficha do cliente certo.
2. Clique em "Registrar visita".
3. Confira a data e a hora em que a visita aconteceu.
4. Se quiser, escreva uma observação curta, como "Veio pedir orçamento".
   Use até 300 caracteres; textos maiores são cortados nesta versão.
5. Clique em "Registrar".
6. Confira a atividade na ficha e a informação "Último retorno".

Uma visita avulsa é registrada manualmente. Criar uma Nota também registra um
retorno automaticamente, sem exigir uma visita duplicada. A visita isolada não
movimenta o Caixa.
Não há botão nesta tela para editar ou apagar uma visita já registrada.

ENTENDER A SITUAÇÃO DE RELACIONAMENTO

Na configuração inicial:

- "Nunca atendido": não há visita nem Nota registrada.
- "Recente": a última atividade foi há até 30 dias.
- "Atenção": entre 31 e 60 dias.
- "Afastado": entre 61 e 90 dias.
- "Há muito tempo": mais de 90 dias.

Essas mensagens ajudam a acompanhar o contato com o cliente. Elas não
informam se ele tem dívida, nem se comprou algo.

"Ativo/Inativo" é a situação do cadastro. "Recente/Afastado" é o tempo
desde o último retorno relevante. Um cliente pode estar ativo e aparecer como
"Há muito tempo" sem contradição.

O campo "Último serviço" mostra a Nota mais recente, a data do atendimento e os
nomes congelados dos serviços. Concluir a produção dias depois aparece na linha
do tempo, mas não muda artificialmente a data do último retorno.

CONSULTAR O HISTÓRICO

- Dentro da ficha, "Atividades do cliente" mostra os eventos daquele cliente.
- Em "Clientes > Histórico", você vê a linha do tempo geral: cadastros,
  alterações, visitas, Notas, conclusões, inativações e reativações, com data e
  responsável.
- O histórico geral e o individual são paginados. Escolha 25, 50 ou 100 itens
  por página e use "Anterior" e "Próxima".
- Clique no nome do cliente de uma atividade para abrir a ficha.

Os controles "Busca", "Cliente", "Atividade", "Usuário", "De" e "Até"
servem para restringir essa consulta. Cliente e Usuário podem permanecer em
"Todos". Para voltar à consulta geral, use "Limpar".

05. CLIENTES: EDITAR, INATIVAR E REATIVAR
======================================================================

EDITAR DADOS

1. Abra a ficha e clique em "Editar".
2. Corrija nome, contato, endereço ou observações.
3. Clique em "Salvar alterações".
4. Confira os dados e o status na ficha.

INATIVAR UM CADASTRO

1. Abra a ficha do cliente.
2. Localize "Outras informações".
3. Clique em "Inativar cliente".
4. Confirme e confira se o status mudou para "Inativo".

Inativar preserva a ficha e as atividades anteriores. Não é uma exclusão.
Para voltar a usar o cadastro, abra a ficha e use "Reativar cliente".

O formulário de dados comuns não muda o status por um campo forjado. Para
controlar a situação do cadastro, use as ações separadas "Inativar cliente" e
"Reativar cliente" na ficha. Elas exigem permissão própria no servidor.

06. SERVIÇOS: CONSULTAR E OPERAR NOTAS
======================================================================

CONSULTAR UM SERVIÇO

1. Entre em "Serviços > Catálogo".
   A página aberta tem o título "Catálogo" e começa mostrando os ativos.
2. Procure o serviço pelo campo de busca.
3. Se necessário, filtre categoria, forma de cobrança ou status.
4. Clique em "Aplicar" e confira o preço e a forma de cobrança.
5. Use "Ver" para abrir os detalhes.

Para achar um serviço inativado, escolha "Inativos" ou "Todos" em Status.
"Limpar" volta à seleção inicial de ativos. Os cartões Total de serviços,
Ativos, Inativos e Categorias ativas são indicadores gerais do catálogo.
A lista tem 25 serviços por página. A ordenação permite comparar nomes,
preços ou datas de cadastro.

CRIAR E ACOMPANHAR UMA NOTA DE SERVIÇO

1. Entre em "Serviços > Nova Nota".
2. Informe o número manual e a série ou bloco, quando houver.
3. Escolha um Cliente ativo.
4. Confira recebimento e prazo previsto.
5. Adicione um ou mais serviços e informe a quantidade permitida pela unidade.
6. Informe entrega ou desconto somente quando fizer parte do atendimento.
7. Confira subtotais, desconto, entrega e total calculados pelo servidor.
8. Salve e acompanhe a Nota em "Serviços > Notas de Serviço".

A Nota congela nomes, unidades, preços e totais. Ao criá-la, o histórico do
Cliente recebe uma atividade de atendimento. Alterar o catálogo depois não muda
a Nota já registrada.

Os estados operacionais seguem a ordem Recebido → Em andamento → Pronto →
Entregue. Uma Nota cancelada fica preservada e não aceita novas operações.

RECEBER UMA NOTA

- "Registrar pagamento" confirma a quitação integral sem mudar o estado
  operacional. Pode ser usado antes ou depois da produção.
- Em uma Nota pronta, "Entregar e receber" faz entrega e recebimento juntos.
- "Entregar sem receber" mantém o financeiro Pendente. Use "Registrar pagamento"
  quando o valor for recebido depois.
- Cartão exige terminal, Débito ou Crédito e quantidade de parcelas.
- Não existe pagamento parcial. Boleto só deve ser escolhido quando já foi pago.
- Nota de total zero já fica Paga e não solicita forma de pagamento.

O pagamento da Nota cria automaticamente uma entrada SYSTEM no Caixa. Nunca
registre outra entrada manual para o mesmo recebimento.


======================================================================
07. ADMINISTRAÇÃO: CATÁLOGO, CATEGORIAS, UNIDADES E PREÇOS
======================================================================

Esta área exige permissões administrativas. O operador comum consulta o catálogo
em Serviços, mas não encontra botões de manutenção.

CADASTRAR UM SERVIÇO

1. Entre em "Administração > Serviços > Novo serviço".
2. Informe um "Código interno", se a empresa usar códigos.
   Exemplo apenas ilustrativo: SRV-010. O código não pode se repetir.
3. Preencha "Nome", que é obrigatório.
4. Escolha uma categoria ou mantenha "Sem categoria".
5. Use "Descrição" para explicar o que está incluído no serviço.
6. Escolha a "Forma de cobrança".
7. Informe o "Preço inicial", maior que zero. Exemplo: 50,00.
8. Deixe "Serviço ativo" marcado se ele já puder ser oferecido.
9. Clique em "Salvar serviço".

Se houver aviso de possível serviço duplicado, confira o nome encontrado.
Use "Cadastrar mesmo assim" somente quando a repetição fizer sentido.

O QUE SIGNIFICA A UNIDADE DE COBRANÇA

- inteiro: aceita somente quantidades inteiras positivas;
- decimal: aceita a precisão configurada para a unidade;
- fixa: a quantidade é sempre 1.

As unidades são universais e configuráveis. Exemplos iniciais incluem unidade,
preço fixo, kg, metro, m², hora, dia, sessão, par, pessoa, km, litro e pacote.
Uma unidade em uso pode ser inativada; o histórico nunca é apagado.

EDITAR OU RETIRAR UM SERVIÇO DA OFERTA

- Use "Editar" para mudar nome, descrição, código, categoria ou cobrança.
- Para mudar o preço, use a ação separada "Alterar preço".
- Trocar a forma de cobrança não converte o valor. Ao mudar de "Por unidade"
  para "Por kg", por exemplo, confira se o preço também precisa ser alterado.
- Use a ação de inativar na ficha para indicar que o serviço deixou de ser
  oferecido. Use a ação de reativar quando ele voltar a ser oferecido.
- Inativar preserva o cadastro e seus preços anteriores.


CRIAR UMA CATEGORIA DE SERVIÇOS

1. Entre em "Administração > Serviços > Categorias".
2. Clique em "+ Nova categoria".
3. Informe um nome, como "Manutenção", se fizer sentido para a empresa.
4. Escreva uma descrição, se necessário.
5. Em "Ordem de exibição", números menores aparecem antes.
6. Mantenha "Categoria ativa" marcada para permitir seu uso.
7. Clique em "Salvar categoria".

A lista mostra quantos serviços estão vinculados a cada categoria.
"Editar" altera seus dados. "Inativar" impede seu uso em novos vínculos,
preservando os serviços que já estavam nela. "Reativar" libera o uso de novo.
Nomes de categoria não podem se repetir.

ALTERAR UM PREÇO

1. Entre em "Administração > Serviços > Preços".
2. Localize o serviço correto.
3. Clique em "Alterar preço".
4. Confira o valor atual mostrado na janela.
5. Digite "Novo preço", maior que zero.
6. Se quiser, informe o motivo, como "Reajuste de tabela".
7. Clique em "Atualizar preço" e confira o novo valor.

A mudança passa a valer a partir do registro da alteração. O preço anterior
continua guardado para consulta. Não existe agendamento de reajuste nessa tela.
Use sempre centavos explícitos, como 1.000,00 para mil reais; evite digitar
apenas 1.000 no campo de preço do serviço.

A aba Preços pode mostrar serviços ativos e inativos; confira o status antes
de mudar um valor. Se o preço foi informado errado, registre outra alteração
com o valor correto e o motivo. Não há edição ou exclusão do preço antigo.
Salvar o mesmo preço novamente também cria uma nova entrada no histórico.

CONSULTAR PREÇOS ANTERIORES

1. Na aba Preços, clique em "Ver histórico" no serviço desejado.
2. Veja cada valor, quando começou e quando deixou de valer.
3. "Vigente" identifica o preço atual.
4. Confira também quem fez a alteração e o motivo, quando informado.

Alterar o catálogo não recebe dinheiro, não cria visita e não corrige
retroativamente um lançamento financeiro que você já registrou.

GERENCIAR UNIDADES

Em "Administração > Serviços > Unidades de cobrança", o Proprietário pode criar,
editar, ordenar, ativar e inativar unidades. Código, nome, símbolo, comportamento
e precisão ficam congelados nos itens das Notas; editar a unidade atual não
altera os documentos anteriores.


======================================================================
08. CAIXA OPERACIONAL E FINANCEIRO
======================================================================

O acesso comum abre "Caixa > Operações". Essa tela mostra apenas os lançamentos
criados pelo próprio usuário nos últimos sete dias, com paginação e sem saldo,
totais, gráficos ou agregações da empresa. Ela serve para conferir o trabalho
recente.

Saldo e análises globais exigem permissão financeira e ficam em
"Administração > Financeiro". Nessa área, use os atalhos para Resumo, Histórico e
Relatórios completos. Os conceitos abaixo pertencem a esse acesso administrativo.

"SALDO ATUAL"
É o acumulado das entradas menos as saídas registradas e ativas até agora,
considerando o valor líquido. Não é apenas o resultado deste mês.

- Positivo: entrou mais dinheiro do que saiu no acumulado.
- Negativo: saiu mais dinheiro do que entrou no acumulado.
- Zerado: entradas e saídas se igualaram, ou ainda não há movimentação.

O saldo reúne as formas de pagamento registradas, como Dinheiro, Pix e
Cartão. Por isso, não representa necessariamente só as notas e moedas que
estão na gaveta. Ele também não consulta automaticamente sua conta bancária.

"SALDO ANTERIOR"
É o que já estava acumulado antes do início do mês atual.

"ENTRADAS DO MÊS"
São os recebimentos do mês até agora, já descontadas as taxas informadas.

"SAÍDAS DO MÊS"
São os pagamentos do mês até agora.

"RESULTADO DO MÊS"
É a diferença entre entradas e saídas desse mês. Um mês pode ter resultado
negativo e ainda haver saldo positivo, se existia dinheiro de antes.

"MOVIMENTAÇÕES RECENTES"
Mostra os últimos lançamentos ativos realizados. A lista completa fica
em "Histórico". Clique na descrição para ver os detalhes.

"ENTRADAS POR PAGAMENTO"
Separa os recebimentos líquidos do mês por forma de pagamento.

"PRINCIPAIS ENTRADAS/SAÍDAS POR CATEGORIA"
Mostra como os valores do mês estão distribuídos. Aparece quando há dados.

EXEMPLO DE LEITURA

Saldo anterior:   R$ 300,00
Entradas do mês:  R$ 500,00
Saídas do mês:    R$ 200,00
Resultado do mês: R$ 300,00
Saldo acumulado:  R$ 600,00

O saldo não é zerado automaticamente quando vira o mês. Não registre de
novo o saldo anterior só porque começou um novo mês: isso duplicaria dinheiro.


======================================================================
09. CAIXA: REGISTRAR UMA ENTRADA
======================================================================

Use Entrada manual para registrar um valor efetivamente recebido que não tenha
sido gerado pelo pagamento de uma Nota.

1. Entre em "Caixa > Novo lançamento" ou clique em "+ Registrar entrada"
   quando esse atalho estiver disponível.
2. Escolha "Entrada".
3. Em "Valor bruto", informe o valor antes de descontar a taxa.
   Digite, por exemplo, 100,00.
4. Confira "Data e hora": deve corresponder ao recebimento.
5. Preencha "Descrição" de forma clara.
6. Escolha uma categoria, se houver. Também é permitido "Sem categoria".
7. Escolha a "Forma de pagamento": Dinheiro, Pix, Cartão, Boleto ou Outro.
   O preenchimento é opcional, mas ajuda na conferência dos relatórios.
8. Use "Observações" para informações complementares.
9. Se houve taxa, marque "Esta entrada possui taxa" e informe o valor
   da taxa em reais. O campo não é uma porcentagem.
10. Confira o "Valor líquido", quando a área de taxa estiver aberta.
11. Clique em "Registrar lançamento".
12. Aguarde "Entrada registrada com sucesso" e confira o lançamento em
    "Operações". Quem possui acesso financeiro também pode conferir no Histórico.

ENTRADA SEM TAXA

Bruto: R$ 100,00. Sem taxa. O Caixa aumenta R$ 100,00.

ENTRADA COM TAXA

Bruto: R$ 100,00. Taxa: R$ 3,00. Líquido: R$ 97,00.
O Caixa aumenta R$ 97,00. A taxa fica identificada nos relatórios.

Não registre a mesma taxa também como saída se ela já foi descontada
nessa entrada: isso descontaria duas vezes o mesmo custo.

ATENÇÕES

- O valor bruto precisa ser maior que zero.
- A taxa não pode ser negativa nem maior que o valor bruto.
- Cartão é uma opção única em um lançamento manual: não há opções separadas de
  crédito e débito nesse formulário. O recebimento de Nota em cartão usa
  terminal, modalidade, parcelas e taxa configurada.
- Escolher Pix não gera cobrança nem confirma recebimento no banco.
- Escolher Boleto não emite boleto. Use para um valor já recebido.
- Promessa de pagamento ou boleto ainda pendente não é dinheiro recebido.
- Pode haver confirmação para uma data futura; datas muito distantes são
  recusadas. No dia a dia, registre a data real do recebimento.

Depois de salvar, o formulário fica pronto para outro lançamento. Isso
não significa que o anterior se perdeu. Consulte o Histórico antes de repetir.


======================================================================
10. CAIXA: REGISTRAR UMA SAÍDA
======================================================================

Use Saída para registrar um pagamento efetivamente realizado.

1. Abra "Caixa > Novo lançamento" e escolha "Saída".
2. Digite o valor pago em "Valor bruto", sempre como um número positivo.
   Exemplo: 80,00. Não digite -80,00.
3. Confira a data e a hora do pagamento.
4. Informe uma descrição, como "Pagamento de material".
5. Selecione categoria e forma de pagamento, se disponíveis.
6. Acrescente observações, se necessário.
7. Clique em "Registrar lançamento".
8. Aguarde "Saída registrada com sucesso" e confira em Operações.

Uma saída de R$ 80,00 reduz o saldo em R$ 80,00.

Saídas não possuem o campo de taxa nesta versão. Registre o valor que
efetivamente saiu. Se houver custos separados, siga a orientação de registro
da empresa e cuide para não contar o mesmo pagamento duas vezes.

Não existe aqui agendamento de conta a pagar: lançar uma saída representa
um pagamento, não apenas uma conta que vencerá no futuro.


======================================================================
11. CAIXA: CONSULTAR O HISTÓRICO
======================================================================

O operador consulta "Caixa > Operações", limitado aos próprios lançamentos dos
últimos sete dias. O Histórico completo abaixo exige permissão financeira.

1. Entre em "Administração > Financeiro" e abra "Histórico completo".
2. Escolha o período:
   - Hoje: a data de hoje.
   - Esta semana: de segunda-feira a domingo da semana atual.
   - Este mês: o mês atual.
   - Este ano: o ano atual.
   - Personalizado: as datas inicial e final que você informar.
3. Para usar datas próprias, marque "Personalizado" e preencha as duas.
4. Se quiser, combine busca, tipo, status, categoria e pagamento.
5. Escolha a ordenação e a quantidade de itens por página.
6. Clique em "Aplicar filtros".
7. Use "Anterior" e "Próxima" para percorrer os resultados.
8. Clique em "Ver" para abrir os detalhes de um lançamento.

A data inicial não pode ser depois da final. "Limpar" remove as escolhas
e volta ao mês atual; não apaga nenhum registro.

O QUE MOSTRAM AS COLUNAS

- Data: quando ocorreu o recebimento ou pagamento.
- Tipo: Entrada ou Saída.
- Descrição: o motivo que foi registrado.
- Categoria: o grupo em que foi classificado.
- Pagamento: a forma informada.
- Bruto: valor antes da taxa.
- Taxa: desconto informado na entrada.
- Líquido: valor considerado para aquele movimento.
- Status: Ativo ou Cancelado.
- Usuário: quem criou o lançamento.
- Ações: Ver, Editar e Cancelar, conforme sua permissão.

REGRA IMPORTANTE DOS CARTÕES DO HISTÓRICO ADMINISTRATIVO

Os cartões de entradas, saídas, taxas e resultado mostram TODOS os
lançamentos ativos do período escolhido, em todas as páginas.

Os outros filtros, como "Somente Saída", "Pix" ou uma descrição, restringem
a lista, mas não restringem esses cartões. Assim, filtrar Pix não transforma
o cartão em um total exclusivo de Pix. Para conferir valores agrupados,
consulte os quadros de "Relatórios".

Registros cancelados podem aparecer na lista, mas nunca entram nos totais.
A quantidade de resultados da lista pode incluir cancelados, conforme
o status selecionado.


======================================================================
12. CAIXA: CORRIGIR OU CANCELAR UM LANÇAMENTO
======================================================================

VER OS DETALHES

A tela de detalhes mostra valores, categoria, pagamento, data, observações,
status e o efeito do lançamento no Caixa. A área "Auditoria do registro"
identifica quem criou, quem alterou e, se houver, quem cancelou, quando e por quê.

EDITAR UM LANÇAMENTO ATIVO

1. Localize o registro no Histórico.
2. Confira se é o registro certo e clique em "Editar".
3. Corrija os campos necessários.
4. Clique em "Salvar alterações".
5. Confira a confirmação e os valores nas telas do Caixa.

É possível corrigir descrição, valor, taxa de entrada, data, categoria,
pagamento e observações. O tipo Entrada/Saída não pode ser trocado na edição.
Se o tipo estiver errado, cancele o registro e faça outro com o tipo correto.

Entradas `SYSTEM` geradas por Pagamento aparecem como automáticas e não podem ser
editadas ou canceladas isoladamente, nem pelo Proprietário. Essa proteção evita
divergência entre Nota, Pagamento e Caixa. O estorno completo não faz parte desta
versão.

CANCELAR UM LANÇAMENTO INCORRETO OU DUPLICADO

1. Localize o lançamento no Histórico e confira seus detalhes.
2. Clique em "Cancelar lançamento" ou na ação "Cancelar" da linha.
3. Informe o motivo obrigatório, como "Registrado em duplicidade".
4. Confirme em "Cancelar lançamento".
5. Confira o status "Cancelado".
6. Confira o saldo e os totais novamente.

O registro permanece visível no histórico, com motivo e responsável, mas
deixa de contar para o saldo e os relatórios. Cancelar uma entrada reduz
o saldo; cancelar uma saída devolve aquele efeito ao saldo.

Não é possível reativar nem editar um lançamento cancelado nesta versão.
Se precisar, faça um novo lançamento correto, conferindo antes o histórico.

Cancelar um registro não estorna Pix, cartão, boleto ou pagamento bancário.
É somente uma correção dentro do livro-caixa. A devolução real de dinheiro
precisa ser tratada separadamente e registrada conforme a orientação da empresa.


======================================================================
13. CAIXA: ORGANIZAR CATEGORIAS
======================================================================

Esta função exige a permissão correspondente; está disponível para o adm.

1. Entre em "Caixa > Novo lançamento".
2. Antes de preencher o lançamento, clique em "Gerenciar categorias".
3. Informe o nome da categoria.
4. Escolha o tipo:
   - Entrada: só pode ser usada em entradas.
   - Saída: só pode ser usada em saídas.
   - Ambos: pode ser usada nos dois tipos.
5. Se quiser, informe descrição e ordem de exibição.
6. Deixe "Categoria ativa" marcada e clique em "Criar categoria".
7. Feche a janela de categorias e preencha o lançamento.

Organize as categorias antes de digitar um lançamento: salvar uma categoria
reabre a tela e pode descartar um lançamento que ainda não foi salvo.

Na mesma área, use "Editar", "Inativar" ou "Reativar".
Inativar retira a categoria das novas escolhas, preservando os vínculos antigos.
O sistema pode recusar uma mudança de tipo que prejudique lançamentos existentes.

As categorias de Caixa são independentes das categorias de Serviços.
Criar uma categoria em Serviços não cria outra igual automaticamente no Caixa.

As formas de pagamento iniciais são Dinheiro, Pix, Cartão, Boleto e Outro.
O Proprietário pode mantê-las em "Administração > Pagamentos e taxas", junto com
terminais genéricos e regras de taxa. Inativar preserva referências históricas.


======================================================================
14. CAIXA: CONSULTAR RELATÓRIOS E GRÁFICOS
======================================================================

Esta função exige `finance.reports.view`; não aparece para o operador comum.

1. Entre em "Administração > Financeiro" e abra "Relatórios".
2. Escolha Hoje, Esta semana, Este mês, Este ano ou Personalizado.
3. Se for Personalizado, informe a data inicial e a final.
4. Clique em "Gerar relatório".
5. Leia os cartões e depois os quadros abaixo.
6. Use "Ver lançamentos" para abrir o Histórico no mesmo período.

O QUE SIGNIFICA CADA VALOR

- Saldo anterior: valor acumulado antes do período.
- Entradas brutas: recebimentos antes do desconto das taxas.
- Taxas: descontos informados nas entradas.
- Entradas líquidas: o que sobrou das entradas depois das taxas.
- Saídas: pagamentos ativos do período.
- Resultado do período: entradas líquidas menos saídas.
- Saldo final do período: saldo anterior somado ao resultado.

ENTRADAS E SAÍDAS POR CATEGORIA
Mostram quantos lançamentos ocorreram em cada grupo e seu total.
"Sem categoria" reúne os lançamentos que não receberam uma classificação.

MOVIMENTO POR FORMA DE PAGAMENTO
Mostra quantidade de lançamentos, valor bruto, taxas e impacto líquido.
"Impacto líquido no caixa" reúne entradas e saídas daquela forma: pode
ser negativo quando houve mais pagamentos que recebimentos por ela.

GRÁFICO DE EVOLUÇÃO
Compara entradas e saídas ao longo do período. Verde representa entradas;
vermelho representa saídas. A tabela abaixo mostra os números e o resultado.
Até 62 dias, o agrupamento é por dia; em períodos maiores, é por mês.
Datas sem movimentação podem não aparecer como uma linha no gráfico.

COMPARAR COM OUTRAS TELAS

Use o mesmo período e lembre que cancelados não contam. O Resumo trabalha
com o mês atual e o saldo até agora. Já Histórico e Relatórios consultam
todo o intervalo selecionado. Um registro com data/hora futura pode aparecer
nesse intervalo sem participar ainda do Saldo atual do Resumo.

Não há botão próprio de exportar planilha, gerar PDF ou enviar relatório
por e-mail nessa tela atual.


======================================================================
15. ADMINISTRAÇÃO E PERMISSÕES
======================================================================

Cada usuário só vê os módulos e botões liberados para seu acesso.

Na configuração inicial dos perfis:

- Proprietário: é o papel técnico legado `admin` exibido com o nome correto da
  função na empresa. Pode acessar Administração, Clientes, Serviços e Caixa.
- Usuário: pode cadastrar e cuidar de Clientes, consultar Serviços,
  criar e operar Notas, receber quando autorizado e criar lançamentos manuais.
  Por padrão, não vê saldo global, não altera catálogo ou taxas e não gerencia
  usuários.
- Entrega: ainda não recebe acesso automático a esses módulos.

Esses são os perfis previstos. Isso não significa que existe uma conta
separada pronta para cada perfil. O acesso de teste deste guia é adm/adm.
Permissões de uma conta podem diferir se tiverem sido ajustadas pelo responsável.

Se um botão não aparecer ou houver "Acesso negado", peça orientação ao
responsável. Isso pode ser uma restrição de acesso, não uma perda de dados.

O QUE EXISTE EM ADMINISTRAÇÃO HOJE

- Visão geral: indicadores clicáveis de produção e Clientes; valores financeiros
  aparecem somente com permissão.
- Serviços: catálogo administrativo, categorias, unidades e preços.
- Financeiro: saldo, Histórico e Relatórios completos.
- Pagamentos e taxas: formas, terminais e regras com vigência.
- Usuários e permissões: criar, editar, ativar/inativar, atribuir papel,
  redefinir senha e configurar a matriz de acesso.
- Empresa: nome, contato, endereço, logo local e fuso horário.

O último Proprietário não pode ser inativado nem perder as permissões essenciais.
Uma gestão delegada não pode assumir o papel Proprietário, alterar essa conta ou
conceder permissões superiores às do próprio responsável pela operação.
Usuários não são apagados fisicamente. Não existe conta de suporte NexPoint,
senha secreta do desenvolvedor ou acesso permanente nesta fase.


======================================================================
16. EXEMPLO DE UMA ROTINA COMPLETA
======================================================================

Exemplo apenas para entender o fluxo; não é necessário lançar estes dados.

1. Uma pessoa chega à empresa.
   Consulte Clientes. Se ainda não houver cadastro, use Novo cliente.

2. Você quer iniciar um atendimento.
   Abra "Serviços > Nova Nota", escolha o Cliente e os serviços e salve. A Nota
   registra o atendimento no histórico automaticamente.

3. A produção começou.
   Abra a Nota e marque "Em andamento". Quando terminar, marque "Pronto".

4. A pessoa efetivamente paga R$ 100,00 por Pix.
   Na própria Nota, use "Registrar pagamento", escolha Pix e confirme. O ERP
   marca a Nota como Paga e cria uma entrada SYSTEM de R$ 100,00 no Caixa.

5. A empresa efetivamente paga R$ 30,00 de uma despesa.
   Crie uma Saída de 30,00, com descrição e pagamento correspondentes.

6. Você confere os registros.
   Em Caixa > Operações, confira seus lançamentos recentes. Com permissão
   financeira, abra o Histórico completo e escolha Hoje.
   Se só existissem esses dois movimentos, o resultado seria R$ 70,00.

7. Você confere o saldo, se tiver permissão financeira.
   Abra Administração > Financeiro. O saldo será o acumulado anterior mais esses
   R$ 70,00.

8. No fim do dia, confira os recebimentos e pagamentos realizados.
   Use Relatórios, se tiver acesso, e compare com os comprovantes da empresa.
   Depois, use Sair e feche a janela.

O Pagamento e o Caixa foram gravados juntos. Se a entrega acontecer antes do
recebimento, use "Entregar sem receber" e registre o pagamento depois.


======================================================================
17. DÚVIDAS FREQUENTES E LIMITAÇÕES ATUAIS
======================================================================

CADASTREI UM CLIENTE E ELE APARECE COMO "NUNCA ATENDIDO".
Isso é esperado até registrar uma visita ou criar uma Nota. Criar apenas a ficha
não conta como retorno.

CADASTREI UM SERVIÇO E O CAIXA CONTINUA IGUAL.
O catálogo não representa um recebimento. Crie a Nota e, quando o valor for
recebido, registre o Pagamento na Nota. Use Entrada manual apenas para valores sem
vínculo com uma Nota.

O PREÇO MUDOU. OS RECEBIMENTOS ANTIGOS TAMBÉM MUDAM?
Não. Alterar o preço do catálogo não muda o histórico financeiro.

UM LANÇAMENTO NÃO APARECE NO HISTÓRICO.
Confira período, busca, filtros, status e outras páginas. Veja se houve
mensagem de sucesso. Não repita o lançamento sem fazer essa conferência.

O TOTAL NÃO É A SOMA DAS LINHAS QUE ESTOU VENDO.
No Histórico financeiro, o total é do período inteiro, não apenas da página ou
do filtro da lista. Cancelados não contam; entradas com taxa contam pelo líquido.
O Caixa > Operações do usuário não exibe totais globais.

O SALDO É DIFERENTE DO DINHEIRO NA GAVETA.
O saldo pode reunir Pix, cartão e outros meios, além de dinheiro. Ele
reflete o que foi registrado no sistema e não faz conferência bancária sozinho.

A BUSCA NÃO MOSTROU O CLIENTE OU A ATIVIDADE.
Confira filtros, período e a página atual. Use "Limpar" para voltar à consulta
geral. Não cadastre a mesma pessoa novamente sem conferir o documento.

QUERO APAGAR UM LANÇAMENTO DO CAIXA.
A ação normal é cancelar com motivo. O histórico fica preservado.
Não há exclusão definitiva nem reativação de cancelados pela tela.

QUERO REGISTRAR UMA CONTA AINDA NÃO PAGA.
Uma Nota entregue pode permanecer financeiramente Pendente até o recebimento,
mas esta versão não oferece contas a receber completas, parcelas ou cobrança
automática. O Caixa registra somente valores realizados.

PRECISO LANÇAR "SALDO INICIAL" TODO MÊS?
Não. O saldo é acumulado. O procedimento especial de saldo de implantação
ainda não tem uma ação pronta nesta versão.

O SISTEMA TRAZ OS DADOS ANTIGOS DO NIL LAV?
Este ERP tem registros próprios locais. Não importa automaticamente
o histórico do sistema anterior nem o consulta durante a operação.

SE A INTERNET CAIR, POSSO CONTINUAR?
Sim, nesta instalação local preparada. O aplicativo não precisa de internet
para login, cadastro e consulta. Não há sincronização com outros dispositivos.

FECHEI SEM QUERER. PERDI OS DADOS?
O que já foi salvo permanece. O que estava sendo digitado sem salvar pode
ter sido perdido. Reabra o ERP pelo modo de abertura preparado no computador.

O APLICATIVO DIZ QUE JÁ EXISTE OUTRA INSTÂNCIA ABERTA.
Procure a janela ERP na barra de tarefas. Use a janela existente ou feche-a
antes de tentar abrir outra. Se persistir, avise o responsável.

A PASTA D:\tutorial ABRE O ERP?
Não. Ela contém este guia de leitura. O aplicativo continua na instalação
local já preparada. Se não tiver um atalho de abertura, peça ao responsável
que disponibilize um; este tutorial não instala nem cria outro aplicativo.

COMO FAÇO BACKUP OU LEVO PARA OUTRO COMPUTADOR?
Não há botão de backup no aplicativo atual. Peça o procedimento ao
responsável pela instalação. Fechar o programa preserva o que foi salvo,
mas não cria uma cópia de segurança por si só.
